# Pinheiro Locações — protótipo do site

Protótipo de site para a Pinheiro Locações (terraplenagem e locação de máquinas pesadas, Teixeira de Freitas – BA).

Site estático: `index.html` + `img/` + `vendor/` (GSAP 3.13 e Lenis 1.1, servidos localmente).
Publicado pelo GitHub Pages. Fotos: Instagram @pinheiro.locacoes, usadas com finalidade de apresentação ao cliente.

Por ser protótipo, o site está com `noindex` e `robots.txt` bloqueando buscadores. Antes do lançamento oficial: remover o `noindex`, liberar o `robots.txt`, gerar `sitemap.xml` e trocar `og:image` para a URL absoluta do domínio final.
